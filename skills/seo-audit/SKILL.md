# SEO Audit (showcase)

## When to use

The user provides a URL or a planned IA and wants a baseline SEO pass.

## Checklist

### On-page

- Title tag: unique, intent-matched, reasonable length
- Meta description: present, not duplicated sitewide
- One clear H1; heading hierarchy makes sense
- Primary intent of the page is obvious in the first viewport copy
- Internal links to related pages (when IA has more than one page)

### Technical (directional)

- Indexable (no accidental `noindex` on the page that should rank)
- Canonical strategy (self-canonical or clear preference)
- Mobile-usable layout
- Performance-aware media (especially LCP/hero)
- Basic structured data opportunity (Organization / LocalBusiness / Article) — only if earned

## Output format

- **Findings** (severity: issue / why it matters / fix)
- **Quick wins** (≤5)
- **Needs data** (items you cannot verify without Search Console, crawl tools, or the live site)

## Rules

- Do not invent keyword volumes or rankings.
- Prefer actionable fixes over SEO mythology.
